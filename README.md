## 📖 About

This repository documents my journey of learning **Python from the ground up**.

Instead of just reading tutorials, I'm focusing on **understanding through doing** — writing code, breaking it, fixing it, and building small programs along the way. Every topic here represents a concept I've studied, practiced, and genuinely understood.

> **Why?** Because the best way to learn programming isn't to memorize syntax — it's to write code and understand *why* it works.

---

Each folder/topic contains:
- ✅ **Concept notes** — quick explanations in plain language
- ✅ **Practice programs** — small scripts applying the concept
- ✅ **Experiments** — edge cases and "what happens if..." code
